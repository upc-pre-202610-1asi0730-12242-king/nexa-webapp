## Overview

The `nexa-webapp` repository contains the Vue 3 single-page application for Nexa. It provides authenticated workspaces for Buyer, Sales, Logistics, and Company Owner users across cold-chain catalog browsing, purchase requests, commercial validation, inventory visibility, dispatch tracking, billing records, and company administration.

This repository is part of the **TB2 delivery** and is currently published as **v3.0.1**.

## Application Areas

| Bounded Context | WebApp Responsibility |
|---|---|
| **IAM** | Login, registration, protected routes, and session state. |
| **Tenant Management** | Workspace and company administration views. |
| **Catalog Management** | Product catalog, brands, categories, and product detail views. |
| **Sales** | Buyer requests, commercial inbox, orders, clients, and promotions. |
| **Warehouse** | Inventory, lots, stock movement, and warehouse views. |
| **Logistics** | Dispatch board, dispatch details, and shipment tracking. |
| **Invoicing** | Business documents, payment methods, invoices, and payment records. |
| **Shared** | Layout, i18n, route guards, API clients, and common status formatting. |
