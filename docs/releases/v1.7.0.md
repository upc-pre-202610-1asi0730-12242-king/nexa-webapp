# Nexa WebApp v1.7.0 - Backend API Integration & Responsive Polish

## Overview
This release closes the technical integration for AV2. It expands the real .NET backend endpoint mapping, provides a complete mobile/desktop layout review, and completes terminology alignment.

## Main Changes

### Backend API Integration
- **Backend Source Configuration:** Bound core modules to `VITE_NEXA_API_BASE_URL` (C# Backend).
- **Route Alignment:** Fixed kebab-case routes for purchase requests, alerts, temperature logs, and timeline events.

### UI Polish
- **Responsive Layouts:** Resolved overflow and alignment issues on Inventory Control, Commercial Dashboard, and Product Catalog.
- **Localization:** Consolidated English and Spanish translations for all core domain terms.
