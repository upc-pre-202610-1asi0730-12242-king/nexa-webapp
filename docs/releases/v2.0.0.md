# Nexa WebApp - Production Release v2.0.0

This release represents **Version 2.0.0** of the **Nexa WebApp**, prepared in coordination with the engineering team (**Gino Torrejón, Joaquin Verde, César Marín**) led by **Diego Sandoval Yucra**.

The WebApp acts as the main user interface for operators (warehouse coordinators, logistics dispatchers) and B2B buyers, consuming REST API endpoints to manage cold-chain distribution workflows.

## 🌟 Key Improvements in v2.0.0

### 1. Complete Backend API Ownership
- **Retired Server Deletion**: Completely removed the retired local `/server` directory and unused local server scripts.
- **Runtime Store Ownership**: Configured Pinia (`src/app/application/stores/data.store.js`) to load core operational collections from Nexa Platform.
- **Environment Sanitation**: Deleted retired local API flags from `.env.development`, `.env.production`, and `.env.example`.
- **Credential Standardization**: Cleared temporary academic sample logins from IAM contexts, replacing them with standardized final user accounts managed by the backend seed process.

### 2. 🛡️ Bounded Context DDD Mapping & Clean Architecture Documentation
- **Layer Boundaries**: Organized directories under Bounded Contexts mapping directly to C# platform subdomains (Catalog, Sales, Warehouse, Logistics, Invoicing, IAM).
- **Ubiquitous Language**: Standardized data entity namespaces (e.g. `CatalogItem`, `Order`, `InventoryItem`, `Invoice`, `Shipment`, `Payment`) between the client Vue modules and C# database structures.
- **Anti-Corruption Layer (ACL)**: Documented the store as an ACL that translates backend resources into clean domain aggregates, protecting presentation modules from breaking schema changes.
- **Compliance Rules**: Created a local `wiki/` directory with 12 engineering guides (Home, Product Scope, API design, commit workflows) to serve as local offline references.

### 3. 🖥️ Layout Responsiveness & Padding Corrections
- **Create Order Catalog Table**: Fixed layout clipping in `create-order-view.vue` on lower resolution monitors by removing rigid inline card styles and setting up responsive CSS flex containers that stack on screens below 1024px.
- **Quick-Actions Operator Grid**: Converted fixed grid columns in `ops.css` to fluid `auto-fit` layouts, preventing navigation buttons from clipping when the viewport collapses.

### 4. 🧹 Retired Files Cleanup
- **Firebase Configuration Removal**: Deleted `firebase.json` from the repository root, as static redirect rules for retired local APIs are not used with Render static hosting.
- **GitIgnore Optimization**: Pruned `.gitignore` to only keep Node/Vite essentials, removing comments and local history folders.
