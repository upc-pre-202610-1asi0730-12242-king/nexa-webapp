# Nexa WebApp v1.8.0 - Backend API Cleanup & Layout Polish

## Summary

This minor release removes the retired local API dependency and moves core operational contexts toward Nexa Platform backend ownership. It also polishes layout responsiveness across sales and operations dashboards.

## Changes

### API & Store Cleanup
- Removed the retired local API runner from devDependencies and scripts.
- Cleaned retired local API parameters from Axios base clients and endpoints.
- Kept global Pinia store focused on backend-loaded runtime collections.
- Cleared academic sample logins, replacing them with standardized final user accounts.

### Layout & Style Polish
- Fixed catalog table responsiveness in `create-order-view.vue` to avoid item clipping on smaller viewports.
- Restructured quick-actions grid in `ops.css` using fluid auto-fit columns.

## Validation

- Verified build compilation passes without warnings (`npm run build`).
- Checked Axios endpoints connection mapping to live platform backend.
- Validated backend-owned store updates.
